# Futureproof Workshop Decks

Static slide decks embedded into Futureproof course units via iframe.

Each deck is a single self-contained HTML file: fonts are embedded as base64,
there are no external requests, and no build step. Edit the file, commit, push.
GitHub Pages serves it.

| Deck | Path |
|---|---|
| Artist Accelerator, Week 1: EP Concept Development | `artist-accelerator/week-1/` |

## Adding a deck

Drop `index.html` in a new folder, add a row above, add a link in the root
`index.html`, commit and push.
